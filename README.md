# AccraCare Hospital Appointment Booking System

Capstone project for the Generation Ghana / Azubi Africa AWS Cloud Computing Programme.
A serverless REST API replaces the mock in-memory data in the frontend with a real
AWS backend: API Gateway, Lambda, DynamoDB, CloudWatch, SNS, and AWS Budgets,
deployed with AWS SAM (built on CloudFormation).

See `DEPLOYMENT_GUIDE.pdf` for the full step-by-step walkthrough. This file is
just a quick-reference.

## Project layout

```
accra-hospital-capstone/
├── template.yaml               # SAM/CloudFormation template: all AWS resources
├── samconfig.toml              # Saved sam deploy defaults
├── events/                     # Sample Lambda test events for `sam local invoke`
├── frontend/                   # Your reviewed frontend (index.html, admin.html, scripts, styles)
│   └── scripts/api.js          # Updated to call the real API instead of mock data
├── backend/
│   ├── lambdas/                # One folder per Lambda function
│   │   ├── get_slots/
│   │   ├── create_slot/
│   │   ├── book_slot/
│   │   ├── get_bookings/
│   │   └── update_slot_status/
│   └── seed/                   # Sample data + loader script for DynamoDB
└── .github/workflows/deploy.yml # CI/CD pipeline (sam build / sam deploy)
```

## Architecture

```
Browser (S3 static website)
      │
      ▼
API Gateway (REST API, generated by SAM)  ── /slots  /slots/{id}/book  /slots/{id}/status  /bookings
      │
      ▼
AWS Lambda (Python 3.12, one function per endpoint)
      │
      ▼
DynamoDB (slots table, bookings table + GSI on slotId)
      │
      ├──> SNS topic  (booking confirmation notification)
      └──> CloudWatch Logs + Alarms (errors, 5xx)

AWS Budgets tracks monthly spend and alerts by email.
Everything above is one CloudFormation stack, defined in template.yaml.
```

## Quick start

```bash
# Build
sam build

# Test a single function locally, no AWS account calls for the compute layer
sam local invoke GetSlotsFunction --event events/get_slots_event.json

# Or run a full local API Gateway + Lambda simulation
sam local start-api
# then curl http://localhost:3000/slots

# First real deploy (guided, asks for your emails interactively)
sam deploy --guided

# Every deploy after that
sam deploy

# Copy the ApiBaseUrl output into frontend/scripts/api.js
sam list stack-outputs --stack-name accra-hospital-capstone

# Seed the demo slots
cd backend/seed
python load_seed_data.py <SlotsTableName_from_output>

# Upload the frontend
aws s3 sync ../../frontend s3://<FrontendBucketName_from_output> --delete
```

Full explanation of every command, prerequisite, and troubleshooting step is in
the deployment guide.
